# 📚 Projeto: Base de Conhecimento DevOps

## Objetivo

Criar uma base de conhecimento organizada contendo anotações, laboratórios, exemplos e projetos desenvolvidos durante cursos de DevOps.

O objetivo é consolidar todo o conteúdo estudado em um único repositório, facilitando revisões, consultas futuras e compartilhamento do conhecimento.
